# Daily Devotional
Static site. Content in `devotions.json` keyed by YYYY-MM-DD (verse text: World English Bible, public domain, via bible-api.com).
Links: `/` (today, America/New_York), `/d/YYYY-MM-DD`, or `/?d=YYYY-MM-DD`.
Add dates: edit `tools/content.py` (or devotions.json directly), commit, push — Render auto-deploys.
